ELviewer · Google Drive 연동 설정 가이드

ELviewer에 "Google 계정 연결"을 넣으려면 개발자(배포하는 사람)가 Google Cloud에 앱을 한 번 등록해야 합니다. 처음이면 15~20분 정도 걸립니다. 각 단계를 마치면 아래의 체크 표시를 눌러 두세요(이 브라우저에만 저장됩니다).

누가 하는 작업인가요? 이 가이드는 개발자가 딱 한 번 하는 작업입니다. 앱을 쓰는 사람들은 Google Cloud를 볼 일이 없고, 앱에서 Google 계정 연결을 눌러 각자 자기 Google 계정으로 로그인하면 끝입니다. 유저마다 자기 드라이브의 폴더를 읽고, 자기 계정에 동기화됩니다.

무료 조건 — 이 방식(Drive 폴더 통째로 읽기)은 Google 심사 없이 최대 100명까지 무료로 쓸 수 있습니다. 첫 로그인 때 "Google에서 확인하지 않은 앱" 경고가 한 번 나오고, 유저가 고급 → ELviewer(으)로 이동을 누르면 됩니다(7단계 그림 참고). 100명을 넘기려면 Google 앱 확인과 보안 심사(유료)가 필요합니다.
그림 안내 — 이 문서의 화면 그림은 메뉴 위치를 설명하기 위해 단순하게 다시 그린 예시입니다. 실제 Google Cloud 콘솔은 디자인이나 메뉴 이름이 조금 다를 수 있습니다(예: "OAuth 동의 화면" ↔ "Google 인증 플랫폼", "사용자 인증 정보" ↔ "클라이언트"). 빨간 테두리와 번호가 누르거나 입력할 곳입니다.

1프로젝트 만들기

약 1분 · 앱을 담을 "그릇"을 만듭니다
  1. console.cloud.google.com에 개발자 Google 계정으로 로그인합니다. (앱을 쓰는 사람의 계정과 상관없습니다) 처음이면 약관 동의 창이 뜹니다.
  2. 위쪽 막대의 프로젝트 선택 단추 → 창 오른쪽 위 새 프로젝트.
  3. 프로젝트 이름에 ELviewer → 만들기. 몇 초 뒤 알림이 뜨면 프로젝트 선택을 눌러 이 프로젝트로 전환합니다.

2Google Drive API 켜기

약 1분
  1. 왼쪽 위 ☰ 메뉴 → API 및 서비스 → 라이브러리. (또는 위쪽 검색창에 "Google Drive API")
  2. Google Drive API를 검색해서 열고 사용을 누릅니다.
이미 켜져 있으면 "사용" 대신 "관리" 단추가 보입니다. 그 상태면 다음 단계로 넘어가세요.

3동의 화면: 앱 정보와 대상

약 3분 · 로그인할 때 보이는 "ELviewer가 권한을 요청합니다" 화면을 만듭니다
  1. ☰ → API 및 서비스 → OAuth 동의 화면. 새 콘솔에서는 Google 인증 플랫폼 개요가 열리고 시작하기 단추가 있습니다.
  2. 앱 정보: 앱 이름 ELviewer, 사용자 지원 이메일은 본인 메일 선택.
  3. 대상: 외부 선택. (개인 Gmail 계정은 "내부"를 고를 수 없습니다)
  4. 연락처 정보: 본인 메일 → 사용자 데이터 정책 동의 → 만들기.

4동의 화면: 권한 범위와 게시

약 3분 · ELviewer가 요청할 권한 두 가지를 등록하고, 로그인이 7일마다 풀리지 않게 게시합니다

4-1. 권한 범위(scope) 추가

  1. 왼쪽 데이터 액세스(옛 화면: 동의 화면 편집 → 범위) → 범위 추가 또는 삭제.
  2. 창 아래쪽 직접 범위 추가 칸에 아래 두 줄을 붙여 넣고 테이블에 추가 → 두 항목이 체크된 상태로 업데이트 → 저장.
https://www.googleapis.com/auth/drive.readonly
https://www.googleapis.com/auth/drive.appdata
두 줄 한 번에
무슨 권한인가요? drive.readonly는 Drive 파일을 읽기만 하는 권한입니다(수정·삭제 불가). drive.appdata는 Drive 안의 숨김 "앱 데이터" 폴더 하나만 쓰는 권한으로, 동기화 파일 elviewer-sync.json이 여기에 저장됩니다. 범위를 저장할 때 "민감한/제한된 범위" 안내가 나와도 그대로 저장하면 됩니다.

4-2. 테스트 사용자 → 앱 게시

  1. (선택) 왼쪽 대상 → 테스트 사용자의 + Add users에 본인 계정을 넣어 두면 게시 전에 먼저 시험해 볼 수 있습니다. 게시 후에는 테스트 사용자 목록과 상관없이 누구나 로그인할 수 있습니다.
  2. 같은 화면 위쪽 게시 상태의 앱 게시 → 확인. 상태가 "프로덕션"으로 바뀌면 완료입니다.
왜 게시하나요? "테스트 중" 상태에서는 PC 로그인이 7일마다 만료되어 매주 다시 로그인해야 합니다. "프로덕션"으로 게시하면 만료되지 않습니다. Google 심사를 받지 않은 앱이라 유저마다 첫 로그인 때 "확인되지 않은 앱" 경고가 한 번 나오고, 최대 100명까지 쓸 수 있습니다(7단계 참고). 게시할 때 "확인 필요" 안내가 떠도 확인을 눌러 게시하면 됩니다.

5PC용 클라이언트 만들기 + JSON 넣기

약 3분 · PC 앱이 브라우저로 로그인할 때 쓰는 열쇠입니다
  1. 왼쪽 클라이언트(옛 화면: 사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID) → + 클라이언트 만들기.
  2. 애플리케이션 유형 데스크톱 앱, 이름 ELviewer PC → 만들기.
  3. 완료 창에서 JSON 다운로드. (창을 닫았다면 클라이언트 목록에서 ELviewer PC 오른쪽의 다운로드 아이콘)
  1. 받은 파일 이름을 google_oauth.json으로 바꿔 아래 위치에 넣습니다. ELviewer 폴더 바로 아래에 둬도 됩니다.
C:\Projects\novelCloud\ELviewer\
└─ src-tauri\
   ├─ Cargo.toml
   ├─ tauri.conf.json
   └─ google_oauth.json   ← 여기 (git에는 올라가지 않음)
C:\Projects\novelCloud\ELviewer\src-tauri\google_oauth.json
파일을 넣은 뒤 PC 앱을 다시 빌드해야 적용됩니다. Claude에게 "google_oauth.json 넣었어"라고 알려주시면 다시 빌드하고 확인합니다. 직접 하려면 ELviewer 폴더에서 npx tauri build.
이 JSON의 보안 비밀번호는 다른 사람과 공유하지 마세요. 실수로 공개됐다면 클라이언트 목록에서 비밀번호를 재설정하면 됩니다.

6Android용 클라이언트 만들기

약 3분 · 휴대폰 앱은 비밀번호 대신 "패키지 이름 + 서명 지문"으로 알아봅니다. 앱을 다시 빌드할 필요는 없습니다
  1. 클라이언트 → + 클라이언트 만들기 → 애플리케이션 유형 Android.
  2. 이름 ELviewer Android, 패키지 이름과 SHA-1 인증서 지문을 아래 값으로 입력 → 만들기.
  3. 디버그 빌드로도 테스트할 계획이면 같은 방법으로 클라이언트를 하나 더 만들고 디버그 SHA-1을 넣습니다.

7ELviewer에서 연결하기 (유저가 하는 부분)

앱을 쓰는 사람마다 각자 자기 계정으로 합니다 · PC 앱은 5단계의 JSON을 넣고 다시 빌드한 버전이어야 합니다
  1. 서재 왼쪽 아래(휴대폰은 ☰ 메뉴 아래) Google 계정 연결.
  2. PC: 브라우저가 열립니다 → 계정 선택 → 경고 화면 → 권한 허용 → "ELviewer에 Google Drive가 연결되었습니다" 페이지가 나오면 브라우저를 닫습니다.
    휴대폰: 계정 선택 → 권한 허용 창이 앱 위에 뜹니다.
  3. Drive 폴더 추가로 소설 폴더를 고르면 서재에 ☁ 표시로 들어옵니다.

문제 해결

이런 메시지가 나오면원인과 해결
PC: "이 빌드에는 Google 로그인 설정이 없습니다"google_oauth.json 없이 빌드된 앱입니다. 5단계 파일을 넣고 다시 빌드하세요.
휴대폰: "Google Cloud에 이 앱이 등록되지 않았습니다"6단계의 패키지 이름 또는 SHA-1이 설치한 APK와 다릅니다. 릴리스 APK면 릴리스 SHA-1, 디버그 빌드면 디버그 SHA-1. 등록 직후라면 몇 분 기다렸다가 다시 시도하세요.
"액세스 차단됨: ELviewer가 Google 인증 절차를 완료하지 않았습니다" / access_denied앱이 아직 "테스트 중"인데 로그인한 계정이 테스트 사용자가 아닙니다. 4-2단계에서 앱을 게시하세요.
"이 앱은 사용자 수 한도에 도달했습니다"확인받지 않은 앱의 100명 한도를 넘었습니다. 더 받으려면 Google 앱 확인·보안 심사가 필요합니다.
PC에서 일주일쯤 지나 "다시 로그인해야 합니다"게시 상태가 "테스트 중"입니다. 4-2단계의 앱 게시를 하고 한 번 다시 연결하세요.
Drive 폴더 추가 화면에 폴더가 안 보임공유받은 폴더는 공유 문서함 탭에 있습니다. 또는 Drive 웹에서 그 폴더에 "바로가기 추가"로 내 드라이브에 넣어 두면 내 드라이브 쪽에서도 보입니다.
연결을 끊고 싶음ELviewer의 연결 해제, 또는 Google 계정 → 보안 → 서드 파티 앱 및 서비스에서 ELviewer 액세스 삭제. 동기화 파일은 Drive 설정 → 앱 관리 → ELviewer → 숨겨진 앱 데이터 삭제로 지울 수 있습니다.
