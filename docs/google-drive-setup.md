# Google Drive 연동 설정

ELviewer의 Google Drive 기능(Drive 폴더 읽기, 읽은 위치·책갈피·하이라이트·메모 동기화)을 넣으려면\n**개발자(배포하는 사람)가** Google Cloud에 앱을 한 번 등록해야 합니다. 15분 정도면 끝납니다.\n\n앱을 쓰는 사람들은 Google Cloud를 볼 일이 없습니다. 앱에서 **Google 계정 연결**을 눌러 **각자 자기 Google 계정**으로\n로그인하면, 유저마다 자기 드라이브의 폴더를 읽고 자기 계정에 동기화됩니다.\n\n**무료 조건**: 이 방식(Drive 폴더 통째로 읽기, `drive.readonly`)은 Google 심사 없이 **최대 100명**까지 무료입니다.\n유저마다 첫 로그인 때 "확인되지 않은 앱" 경고가 한 번 나옵니다(고급 → ELviewer(으)로 이동). 100명을 넘기려면 Google 앱 확인과 보안 심사(유료)가 필요합니다.

## 동작 방식 요약

- **읽기 권한**: `drive.readonly`(Drive 파일 읽기 전용), `drive.appdata`(앱 전용 숨김 폴더). 내 Drive의 파일을 수정·삭제하지 않습니다.
- **동기화 파일**: Drive의 숨김 앱 데이터 폴더에 `elviewer-sync.json` 하나로 저장됩니다. Drive 화면에는 보이지 않으며, Drive 설정 → 앱 관리에서 지울 수 있습니다.
- **동기화 시점**: 앱 시작, 책을 닫을 때, 앱이 백그라운드로 갈 때·돌아올 때, PC 창을 닫을 때, 5분마다.
- **같은 책 판단 기준**: 파일 이름과 크기(이미지 폴더는 폴더 이름과 이미지 수). PC의 로컬 폴더에 있는 책과 휴대폰의 Drive 폴더에 있는 같은 파일도 서로 동기화됩니다.
- **읽는 중인 책**: 다른 기기에서 더 읽은 위치가 들어오면 바로 옮기지 않고 "다른 기기에서 ○○%까지 읽었습니다 [이동]" 알림을 띄웁니다.

## 1. 프로젝트와 API

1. <https://console.cloud.google.com/> → 상단 프로젝트 선택 → **새 프로젝트** (이름 예: `ELviewer`).
2. **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용**.

## 2. OAuth 동의 화면 (Google 인증 플랫폼)

1. **API 및 서비스 → OAuth 동의 화면** → 시작하기.
2. 앱 이름 `ELviewer`, 사용자 지원 이메일·개발자 연락처에 본인 메일.
3. 대상: **외부**.
4. **데이터 액세스 → 범위 추가**에서 아래 두 개를 추가합니다.
   - `https://www.googleapis.com/auth/drive.readonly`
   - `https://www.googleapis.com/auth/drive.appdata`
5. (선택) **대상 → 테스트 사용자**에 본인 계정을 넣어 두면 게시 전에 먼저 시험해 볼 수 있습니다. 게시 후에는 누구나 로그인할 수 있습니다.

> **게시 상태**: "테스트" 상태에서는 테스트 사용자만 로그인할 수 있고 PC 로그인이 **7일마다 만료**됩니다.
> **대상 → 앱 게시**로 "프로덕션"으로 바꾸세요. 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 한 번 나오는데,
> **고급 → ELviewer(으)로 이동**을 누르면 됩니다. 검증 없이 100명까지 쓸 수 있습니다.
> (Play 스토어에 공개 배포하려면 `drive.readonly`가 제한 범위라 Google 보안 심사가 필요합니다.)

## 3. PC용 클라이언트 (데스크톱 앱)

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형 **데스크톱 앱**, 이름 `ELviewer PC`.
3. 만든 뒤 **JSON 다운로드** → 파일 이름을 `google_oauth.json`으로 바꿔서 `ELviewer/src-tauri/google_oauth.json`(또는 `ELviewer/google_oauth.json`)에 둡니다.
   (git에 올라가지 않도록 `.gitignore`에 들어 있습니다.)
4. PC 앱을 다시 빌드합니다: `npx tauri build`. 이 파일 없이 빌드하면 PC에서는 "이 빌드에는 Google 로그인 설정이 없습니다"로 표시됩니다.

## 4. 휴대폰용 클라이언트 (Android)

Android는 클라이언트 비밀번호 없이 **패키지 이름 + 서명 키 SHA-1**로 앱을 알아봅니다. 코드나 빌드에 넣을 값은 없습니다.

1. **사용자 인증 정보 만들기 → OAuth 클라이언트 ID → Android**.
2. 패키지 이름: `com.elviewer.app`
3. SHA-1 인증서 지문 – 설치하는 APK를 서명한 키 기준으로 만듭니다. 필요한 만큼 클라이언트를 여러 개 만들면 됩니다.

| 용도 | SHA-1 |
|---|---|
| 릴리스 APK (`release/android/ELviewer-*.apk`, 업로드 키) | `CD:00:48:A0:28:E5:12:C1:8A:B2:CE:AE:3D:9A:52:BB:10:45:EA:69` |
| 디버그 빌드 (이 PC의 디버그 키) | `A5:36:B2:72:56:80:F8:D9:03:44:2D:CC:A9:D4:B2:F9:24:AD:B2:A1` |
| Play 스토어 배포 시 | Play Console → 테스트 및 출시 → 앱 무결성 → **앱 서명 키** SHA-1을 추가 |

등록 후 몇 분 뒤부터 적용됩니다. 휴대폰에서 연결할 때 "Google Cloud에 이 앱이 등록되지 않았습니다"가 나오면
패키지 이름이나 SHA-1이 맞지 않는 것입니다.

키 지문 다시 확인하기:

```powershell
keytool -list -v -keystore $env:USERPROFILE\.elviewer\elviewer-upload.jks -alias upload
```

## 5. 사용

1. 서재 왼쪽(휴대폰은 ☰ 메뉴) 아래 **Google 계정 연결**.
   - PC: 브라우저가 열리고 로그인 → "연결되었습니다" 페이지가 나오면 창을 닫습니다.
   - 휴대폰: Google 계정 선택 → 권한 허용.
2. **Drive 폴더 추가**로 소설 폴더를 고릅니다. 하위 폴더와 64 MB 이하 zip/7z 안의 파일까지 읽습니다.
3. 열어 본 책은 기기에 저장되어(최대 2 GB, 오래 안 연 것부터 정리) 오프라인에서도 열립니다.

로그아웃은 같은 곳의 **연결 해제**. Google 계정의 "서드 파티 액세스"에서도 끊을 수 있습니다.
